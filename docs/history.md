# Aeon project history

Aeon began in 2003 as a conversational software project and has since been explored across desktop, mobile, and robotics-related prototypes. The project has used several implementation languages and hardware platforms while retaining a focus on interactive personality and dialogue.

The current repository concentrates on the .NET runtime, configurable personality files, and reproducible conversational behavior. Historical publications, presentations, patent material, and development references are retained elsewhere in this directory.
