About local learning in the application

Type `learn` at the terminal to enter an explicit review flow. Enter one literal phrase and one literal response, review the pair, and type `yes` to save it. The runtime writes a uniquely named `.aeon` file only below its configured `personality/learned` directory, then loads that file for the current session. Blank or invalid entries, and any review that is not confirmed, create no file.
